# Machine-Learning

Coursework for the NYCU AIIT Machine Learning class — experiment reports, notebooks, and
selected results for each assignment.

| Folder | Topic |
|---|---|
| [HW1](HW1) | KNN and Nearest Centroid classification on Iris |
| [HW2](HW2) | Decision Tree, Random Forest, Extra Trees, and AdaBoost on Iris |
| [HW3](HW3) | Logistic regression & GDA theory, Newton's-method implementation (CS229 PS1) |
| [HW4](HW4) | LoRA fine-tuning of LLaMA-3 with unsloth |
| [HW5](HW5) | Poisson regression and GLM convexity (CS229 PS1) |
| [HW6](HW6) | Kaggle dogs-vs-cats transfer-learning study |
| [HW7](HW7) | Reflection on a guest lecture (RL, imbalanced data, LLMs) |
| [Final](Final) | Real-time email monitoring and spam/phishing alert system |

Each folder contains the notebook(s), the experiment report (PDF), and a `README.md`
summarizing the approach and results, with a `Colab` badge to run the notebook directly
where code is available.
